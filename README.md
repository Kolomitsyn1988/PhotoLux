# Photo Lux — веб-редактор и конвертер фотографий на ASP.NET Core

Сайт для загрузки фотографий, их коррекции «ползунками» (как в Photoshop/Lightroom)
в реальном времени и конвертации в JPEG / PNG / WebP с обработкой
полноразмерного оригинала на сервере.

![Photo Lux](https://img.shields.io/badge/.NET-10.0-blue) — светлая тема в духе
Apple/Metro: плитки-карточки, стеклянная шапка, логотип-диафрагма.

## Запуск

Требуется .NET SDK 8.0 или новее (проект нацелен на `net10.0`, при необходимости
поменяйте `<TargetFramework>` в `PhotoStudio.csproj`).

```bash
cd PhotoStudio
dotnet run
```

Сайт откроется на **http://localhost:5080** (порт задаётся в `Properties/launchSettings.json`).

## Возможности

- **Мультизагрузка**: drag & drop, Ctrl+V или клик по стартовой зоне — можно выбрать
  сразу несколько файлов. Галерея миниатюр слева: переключение между фото кликом
  (настройки каждого фото сохраняются), удаление крестиком, кнопка «Очистить» с
  модальным подтверждением убирает все фото. Форматы: JPEG, PNG, WebP, BMP, GIF;
  до 40 МБ.
- **Сохранить галерею (ZIP)**: все фото галереи экспортируются с их настройками
  одним архивом (`photolux-gallery.zip`); необрабатываемые файлы попадают в
  `_ошибки.txt` внутри архива.
- **Отмена правок**: кнопка «↩ Отменить» / Ctrl+Z откатывает ползунки, пресеты и
  сбросы (история на каждое фото, до 50 шагов).
- Живой предпросмотр на WebGL (GPU), все ползунки применяются мгновенно:
  - **Свет и тон**: экспозиция (EV), яркость, контраст, гамма;
  - **Цвет**: температура, оттенок, насыщенность, красочность (vibrance);
  - **Портрет**: смягчение кожи (обрабатывает только «кожные» тона, сохраняя
    глаза/контуры), сияние (мягкий свет);
  - **Детализация**: резкость, размытие;
  - **Эффекты**: виньетка, сепия, синий (холодный) оттенок;
  - **Ч/Б микс**: обесцвечивание + поканальные веса красного/зелёного/синего
    (как в Lightroom: «синие −40» делает небо драматичнее).
- У каждого ползунка есть **ручной ввод числа** (синхронизирован с ползунком),
  двойной клик по ползунку/подписи сбрасывает значение.
- **Поворот ±90°**: кнопки ↺/↻ рядом с зумом, вращается и предпросмотр (WebGL),
  и экспорт (сервер); ориентация сохраняется для каждого фото.
- **Превью на плитках пресетов**: каждая плитка рендерит мини-канвас активного
  фото с фильтром пресета (тот же WebGL-пайплайн, 4:3 кроп по центру).
- RGB-гистограмма закреплена вверху панели (не прокручивается) и обновляется
  вместе с предпросмотром.
- **Зум предпросмотра**: кнопки − / % / + и «Вписать» под фотографией; увеличенное
  изображение прокручивается колесом и полосами прокрутки.
- **28 пресетов** в трёх группах:
  - *Базовые*: Оригинал, Тёплый вечер, Холодный рассвет, Нуар, Вивиант, Мягкий фокус;
  - *Instagram*: Clarendon, Gingham, Moon, Lark, Reyes, Juno, Ludwig, Aden, Slumber,
    Crema, Perpetua, Amaro, Hudson, Valencia, Nashville, 1977, Lo-Fi, Willow;
  - *Lightroom*: Контраст, Матовый, Кино, Драма, Плёнка, Холод, Золотой час, Муди,
    Вельвия, Блейкаут, Кросс-процесс, Ч/Б Контраст, Портрет.
- Кнопка «Сравнить» (удерживать) показывает оригинал.
- **Тёмная/светлая тема**: переключатель в шапке (🌙/☀️), выбор запоминается
  в localStorage.
- Экспорт: формат (JPEG/PNG/WebP), качество, ограничение размеров. Сервер применяет
  те же формулы к полноразмерному оригиналу (ImageSharp).

## Как это устроено

```
PhotoStudio/
├── Controllers/
│   ├── HomeController.cs          # страница редактора
│   └── ImagesController.cs       # REST API: upload / original / export
├── Models/ExportModels.cs         # DTO: настройки коррекции, запрос экспорта
├── Services/
│   ├── ImageStore.cs              # хранение оригиналов (App_Data/uploads, TTL 12 ч)
│   └── ImageProcessingService.cs  # пайплайн эффектов + кодирование (ImageSharp)
├── Views/Home/Index.cshtml        # разметка редактора (логотип — инлайн-SVG)
└── wwwroot/
    ├── css/site.css               # светлая тема Apple/Metro
    └── js/editor.js               # WebGL-пайплайн предпросмотра + UI
```

### Предпросмотр (клиент, WebGL)

Пять проходов: размытие пользователя по горизонтали и вертикали (FBO A/B),
мягкое размытие для портретных эффектов (FBO C/D), затем резкость (крестовое
ядро 3×3) + смягчение кожи (маска «кожных» тонов с сохранением краёв) + сияние
(screen-blend) + вся цветовая математика + виньетка. Оригинал уменьшается до
2048 px по большей стороне.

### Экспорт (сервер, ImageSharp)

Порядок операций и формулы совпадают с шейдером один в один
(`ImageProcessingService` ↔ `editor.js`, фрагмент `FRAG_COLOR`):
размытие → резкость → портретные эффекты → экспозиция → температура → гамма →
яркость → контраст → насыщенность → красочность → оттенок (матрица CSS
hue-rotate) → ч/б (поканальные веса) → сепия → синий тон → виньетка.

Радиусы размытия, резкости и мягкого размытия масштабируются от ширины
предпросмотра к ширине экспорта (`scale = ширина_экспорта / previewWidth`).
Попиксельное совпадение с предпросмотром приблизительное (алгоритмы размытия
немного различаются), цветовая математика — точная.

### API

| Метод | Маршрут | Описание |
|---|---|---|
| POST | `/api/images/upload` | multipart `file` → `{id, name, width, height, ext, url}` |
| GET | `/api/images/{id}/original` | оригинал для предпросмотра |
| POST | `/api/images/export` | JSON-запрос → файл результата |
| POST | `/api/images/export-archive` | массив элементов галереи → ZIP-архив |

Тело экспорта:

```json
{
  "id": "...",
  "format": "jpeg | png | webp",
  "quality": 90,
  "previewWidth": 1600,
  "maxWidth": null, "maxHeight": null,
  "adjustments": {
    "exposure": 0.5, "brightness": 0.1, "contrast": 0.2, "gamma": 1,
    "temperature": -0.3, "hue": 0, "saturation": 0.1, "vibrance": 0.2,
    "skin": 0.5, "glow": 0.2, "sharpen": 0.4, "blur": 0,
    "vignette": 0.5, "grayscale": 1, "sepia": 0, "blue": 0.4,
    "bwRed": 0.3, "bwGreen": 0, "bwBlue": -0.4
  }
}
```

## Безопасность

- Белый список расширений + проверка содержимого (`Image.Identify`).
- **TIFF-декодер отключён**: декодеры регистрируются явно (JPEG/PNG/WebP/BMP/GIF),
  поэтому известные уязвимости TIFF/BigTIFF (GHSA-v76p-62qx-wwq2, GHSA-wmxv-xphr-5c9g),
  исправленные только в ImageSharp 3.2, недостижимы — даже для файла, переименованного
  в `.jpg`. Если обновитесь на ImageSharp 3.2+, имейте в виду: Release-сборка требует
  лицензию Six Labors (Split License).
- Лимит размера 40 МБ, GUID-идентификаторы файлов, имена файлов очищаются от
  небезопасных символов.
- Загруженные файлы считаются временными: чистятся при старте (старше 12 часов).

## Идеи для развития

- Превью-миниатюры на плитках пресетов (рендер мини-канваса с фильтром).
- Отмена действий (Ctrl+Z), кривые и уровни, локальные фильтры (кисть).
- Пакетный экспорт всей галереи в ZIP, сохранение своих пресетов в базе.
- Фоновая обработка больших файлов (очередь + SignalR прогресс).
